## Задание

Создать обобщенный класс `CVector`. Реализовать индексатор, конструкторы, финализатор, необходимые методы и операции: `-` для разности двух векторов, `+` для сложения элементов вектора с целым числом, `==` и `!=`. Использовать `ref`, `out`, `is` или `as`, `foreach` и обработку исключений.

В условии класс назван как `время CVector`, но заданные операции относятся к числовому вектору. Поэтому реализован обобщенный числовой вектор.

## Логика решения

Класс `CVector<T>` ограничивает тип параметра интерфейсом `INumber<T>`. Ограничение гарантирует, что для элементов доступны ноль, сложение, вычитание и сравнение. В отличие от лабораторной работы № 6, здесь не требуется `dynamic`, а арифметика проверяется компилятором.

Операторы создают новый результат и не изменяют исходные векторы. Равенство выполняется по размеру и значениям элементов. Индексатор проверяет границы.

Метод `ReplaceAt` принимает индекс через `ref`. Если передан отрицательный индекс, он пересчитывается от конца и возвращается вызывающему коду. Предыдущее значение элемента возвращается через `out`. Метод `TryDescribe` использует `is`, а реализация `IEnumerable<T>` позволяет применять `foreach`.

## Вопросы для защиты

### 1. Что такое ограничение обобщенного типа?

Ограничение сообщает компилятору, какие возможности обязан иметь тип `T`. Запись `where T : INumber<T>` разрешает использовать числовые операции для элементов.

### 2. Для чего нужен индексатор?

Индексатор дает объекту синтаксис массива. Выражение `vector[index]` вызывает `get`, а присваивание вызывает `set`. Внутри можно добавить проверку границ.

### 3. Почему `==` и `!=` реализуются вместе?

C# требует согласованную перегрузку этой пары. Если `==` считает объекты равными, `!=` должен вернуть противоположный результат. Также переопределяются `Equals` и `GetHashCode`.

### 4. Как используются `ref` и `out` в методе `ReplaceAt`?

Через `ref` метод получает и при необходимости изменяет индекс. Через `out` он обязательно возвращает прежнее значение элемента. Это демонстрирует два способа передачи параметров по ссылке.

### 5. Почему финализатор здесь не нужен в обычной программе?

Вектор хранит управляемый массив, память которого освобождает сборщик мусора. Финализатор добавлен только по условию. Он был бы оправдан при прямом владении неуправляемым ресурсом.
