## Задание

Для варианта 9 требуется контейнер `vector` со встроенным типом `double`. Необходимо заполнить и просмотреть контейнер, удалить и заменить элементы, выполнить просмотр через итераторы, удалить `n` элементов после заданного, отсортировать значения по убыванию. Эти действия нужно повторить с пользовательским классом лабораторной работы № 1. Затем требуется найти заданный пользовательский объект и подсчитать элементы, подходящие под условие.

## Адаптация к C#

`vector` и STL относятся к C++. В C# ближайшим стандартным контейнером является `List<T>`, а стандартные алгоритмы представлены методами коллекций и LINQ. Потоковые операторы `>>` и `<<` в C# не применяются для обычного ввода и вывода объектов, поэтому используются методы `Parse` и `ToString`.

## Логика решения

Список `List<double>` проходит все требуемые этапы: заполнение, удаление, замена, перебор, групповое удаление и сортировка. Обобщенный метод `RemoveAfter<T>` подходит для любого списка.

Для пользовательского типа используется `TimeOfDay`. Он реализует `IComparable<TimeOfDay>` для сортировки и `IEquatable<TimeOfDay>` для поиска по значению. Метод `Find` ищет заданное время, а методы `Count` подсчитывают числа больше 5 и объекты времени после полудня.

## Вопросы для защиты

### 1. Что такое обобщенная коллекция?

Обобщенная коллекция хранит элементы указанного типа. `List<double>` принимает только `double`, а `List<TimeOfDay>` принимает только объекты `TimeOfDay`. Ошибки типов обнаруживаются при компиляции.

### 2. Чем `List<T>` отличается от массива?

Размер массива фиксируется при создании. `List<T>` автоматически изменяет внутреннюю емкость и предоставляет методы `Add`, `Remove`, `Find`, `Sort` и `RemoveRange`.

### 3. Что используется как итератор в C#?

Коллекция реализует `IEnumerable<T>` и предоставляет перечислитель `IEnumerator<T>`. Цикл `foreach` автоматически получает перечислитель и по очереди обращается к элементам.

### 4. Зачем класс времени реализует `IComparable<TimeOfDay>`?

Интерфейс определяет естественный порядок объектов. Метод `CompareTo` сравнивает количество секунд от начала суток, поэтому времена можно сортировать.

### 5. Что такое LINQ?

LINQ является набором операций над последовательностями. В работе метод `Count` получает условие в виде лямбда-выражения и подсчитывает только подходящие элементы.
