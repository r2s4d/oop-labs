## Задание

Расширить проект лабораторной работы № 2. Использовать абстрактный класс как основу иерархии и определить абстрактные методы. Добавить статическую ссылку на начало связанного списка объектов и статический метод просмотра списка. Создать объекты разных классов, добавить их в список и вывести список вызовом через класс.

## Логика решения

Класс `TransportVehicle` объявлен абстрактным. Он хранит общие характеристики транспорта, но не задает конкретный способ формирования описания. Метод `GetDescription` объявлен как `abstract`, поэтому каждый конкретный транспорт обязан его реализовать.

В базовом классе находится статическое поле `_head`. Оно ссылается на первый объект внутреннего класса `TransportNode`. Каждый узел хранит объект транспорта и ссылку на следующий узел. Метод `AddToRegistry` добавляет новый узел в начало списка. Метод `ShowRegistry` последовательно проходит по ссылкам `Next` и вызывает полиморфный метод `GetDescription`.

## Вопросы для защиты

### 1. Что такое абстрактный класс?

Абстрактный класс служит общей основой иерархии. Его нельзя создать оператором `new`, но в нем можно объявлять поля, свойства, обычные методы и абстрактные методы.

### 2. Что такое абстрактный метод?

Абстрактный метод имеет только объявление без реализации. Неабстрактный производный класс обязан переопределить его с помощью `override`.

### 3. Для чего используется статическое поле?

Статическое поле принадлежит самому классу и существует в единственном экземпляре. Поэтому `_head` является общим началом списка для автомобилей и поездов.

### 4. Как устроен односвязный список?

Список состоит из узлов. Каждый узел хранит значение и ссылку на следующий узел. Последний узел содержит `null` в свойстве `Next`.

### 5. Почему `ShowRegistry` вызывается через класс?

Метод объявлен с модификатором `static` и не относится к отдельному объекту. Правильная форма вызова имеет вид `TransportVehicle.ShowRegistry()`.
