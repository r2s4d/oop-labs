## Задание

Модифицировать проект лабораторной работы № 5 и создать обобщенный класс `CVector<T>`. Проверить его для стандартных типов `int`, `double` и пользовательского класса из предыдущих работ. Создать обобщенный метод, который возвращает максимально близкий к заданному элемент вектора.

## Логика решения

Класс `CVector<T>` хранит массив элементов неизвестного заранее типа `T`. Он реализует `IEnumerable<T>`, поэтому элементы можно перебирать циклом `foreach`. Равенство проверяется через `EqualityComparer<T>.Default`.

Арифметические операторы сохранены из лабораторной работы № 5. Так как не каждый возможный тип `T` поддерживает `+` и `-`, внутри операторов применяется `dynamic`. Если тип не поддерживает нужную операцию, класс формирует понятное `InvalidOperationException`.

Метод `FindClosest<T>` не предполагает, как измеряется расстояние между объектами. Функция расстояния передается параметром `Func<T, T, double>`. Для чисел используется разность, а для `TimeOfDay` сравнивается количество секунд от начала суток.

## Вопросы для защиты

### 1. Что такое обобщенный класс?

Обобщенный класс работает с типом, который указывается при создании объекта. Например, `CVector<int>` хранит целые числа, а `CVector<TimeOfDay>` хранит объекты времени. Основной код класса при этом не дублируется.

### 2. Что обозначает параметр `T`?

`T` является параметром типа. Во время использования класса он заменяется конкретным типом, указанным в угловых скобках.

### 3. Зачем `CVector<T>` реализует `IEnumerable<T>`?

Интерфейс делает объект последовательностью. Благодаря методу `GetEnumerator` вектор можно использовать в `foreach` и передавать методам, которые принимают `IEnumerable<T>`.

### 4. Почему функция расстояния передается параметром?

Для разных типов близость вычисляется по-разному. Числа сравниваются по разности, а время по количеству секунд. Передаваемая функция позволяет сохранить один обобщенный алгоритм.

### 5. Какой недостаток есть у использования `dynamic`?

Компилятор не проверяет наличие операции заранее. Если тип не поддерживает сложение или вычитание, ошибка обнаруживается во время выполнения. В работе эта ошибка перехватывается и заменяется понятным исключением.
