## Задание

Создать класс `CVector`. Реализовать конструкторы, финализатор и необходимые методы. Перегрузить операции: `-` для разности двух векторов, `+` для прибавления целого числа ко всем элементам, `!=` для проверки на неравенство и `[]` для доступа к элементу по индексу. Написать программу проверки всех операций.

В тексте варианта класс назван как `время CVector`, но перечисленные операции относятся к вектору. Поэтому реализован одномерный числовой вектор.

## Логика решения

Элементы хранятся в закрытом массиве `_items`. Конструктор из последовательности копирует входные данные, чтобы внешний код не мог изменить внутренний массив. Конструктор копирования также создает новый массив.

Оператор `-` проверяет размеры и создает новый вектор с поэлементной разностью. Оператор `+` создает новый вектор и прибавляет число к каждому элементу. Исходные операнды не изменяются.

Индексатор проверяет границы перед чтением или записью. Для корректной перегрузки `!=` также реализованы `==`, `Equals` и `GetHashCode`.

## Вопросы для защиты

### 1. Что такое перегрузка операторов?

Перегрузка задает поведение стандартного оператора для пользовательского класса. Например, выражение `first - second` вызывает метод `operator -` класса `CVector`.

### 2. Почему операторы объявляются статическими?

Оператор относится к типу и получает операнды через параметры. Он не вызывается как обычный метод конкретного объекта, поэтому в C# оператор должен быть `public static`.

### 3. Почему вместе с `!=` реализован оператор `==`?

C# требует перегружать `==` и `!=` парой. Их результаты должны быть согласованы. В данной работе `!=` возвращает отрицание результата `==`.

### 4. Что такое индексатор?

Индексатор позволяет обращаться к объекту с помощью квадратных скобок. Запись `vector[2]` вызывает секцию `get`, а присваивание `vector[2] = 10` вызывает секцию `set`.

### 5. Почему операции возвращают новый вектор?

Такой подход не изменяет исходные операнды и соответствует обычному поведению арифметических выражений. Результат можно сохранить отдельно, а исходные данные останутся прежними.
