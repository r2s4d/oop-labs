## Задание

Модифицировать проект лабораторной работы № 6. Реализовать ввод и вывод данных на экран и в текстовый файл с использованием потоковых классов. Считывать количество, типы и значения объектов. Создать и обработать не менее пяти различных исключительных ситуаций. Построить иерархию классов исключений.

## Логика решения

Класс `VectorFileService` использует `StreamWriter` и `StreamReader`. Первая строка файла содержит число объектов. Остальные строки имеют формат `тип|значение1;значение2`. Поддерживаются векторы `int`, `double` и `TimeOfDay`.

Все прикладные исключения наследуются от `LabException`. Реализованы отдельные типы для отрицательного размера, неверного индекса, разных размеров, поврежденных данных, файловой ошибки и неправильного времени.

Программа сначала выполняет успешную запись и чтение. Затем намеренно создает шесть ошибочных ситуаций. Каждая ошибка перехватывается, а блок `finally` подтверждает завершение проверки.

## Вопросы для защиты

### 1. Для чего нужны исключения?

Исключения отделяют обработку ошибки от основного алгоритма. Метод сообщает о невозможности продолжить работу с помощью `throw`, а вызывающий код принимает решение в блоке `catch`.

### 2. Чем `throw` отличается от `throw exception` внутри `catch`?

Оператор `throw` без аргумента повторно выбрасывает текущее исключение и сохраняет исходный стек вызовов. Запись `throw exception` начинает стек с текущего места и затрудняет поиск первоначальной причины.

### 3. Когда выполняется блок `finally`?

`finally` выполняется после `try` и `catch` независимо от того, возникло исключение или нет. Его используют для действий, которые должны произойти в любом случае.

### 4. Зачем создавать собственную иерархию исключений?

Она позволяет отличать ошибки предметной области от системных ошибок. Можно перехватить конкретную проблему или все ошибки лабораторной работы одним `catch (LabException)`.

### 5. Для чего используется `using` при работе с файлами?

`using` гарантирует вызов `Dispose` у потока. Файл будет закрыт даже при исключении, поэтому другие программы смогут получить к нему доступ, а буфер записи будет обработан корректно.
