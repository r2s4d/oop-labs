## Задание

Использовать проект лабораторной работы № 3. Реализовать методы-итераторы для двух запросов: определить количество транспортных средств указанного вида в автопарке и вычислить количество мест во всех вагонах поездов.

## Логика решения

Абстрактная иерархия и связанный список сохранены из предыдущей работы. Метод `EnumerateRegistry` использует `yield return` и последовательно возвращает транспорт из связанного списка.

Класс `VehicleParkAnalyzer` содержит обобщенный итератор `SelectByType<T>`. Внутри него оператор `is` проверяет фактический тип каждого объекта. На основе этого итератора метод `CountByType<T>` подсчитывает автомобили или поезда. Метод `CountAllTrainSeats` выбирает только поезда и складывает результаты `GetTotalSeats`.

## Вопросы для защиты

### 1. Что означает динамическая идентификация типа?

Это определение фактического типа объекта во время выполнения программы. Ссылка базового типа может указывать на объект производного класса, а оператор `is` позволяет проверить этот производный тип.

### 2. Чем оператор `is` отличается от явного приведения типа?

Оператор `is` сначала безопасно проверяет совместимость типов. Неудачное явное приведение выбрасывает `InvalidCastException`. В записи `value is Train train` проверка и получение типизированной переменной выполняются вместе.

### 3. Что делает `yield return`?

`yield return` возвращает очередной элемент последовательности и приостанавливает метод. Следующий элемент вычисляется только при следующем обращении итератора.

### 4. Зачем метод `SelectByType` сделан обобщенным?

Один метод может выбирать автомобили, поезда и другие будущие виды транспорта. Тип указывается при вызове, например `SelectByType<Train>`.

### 5. Где в работе используется полиморфизм?

Все элементы имеют базовый тип `TransportVehicle`, но вызов `GetDescription` выполняет реализацию класса `Car` или `Train`. Анализатор также работает с общей последовательностью базового типа.
