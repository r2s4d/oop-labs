## Запуск

Для работы требуется .NET SDK с поддержкой `net8.0`.

Запуск всего решения:

```text
dotnet build OopLabs.sln
```

Запуск отдельной лабораторной работы:

```text
dotnet run --project Lab01/Lab01.csproj
```

Вместо `Lab01` можно указать номер любого другого проекта.

## Примечание по условиям

Номер 19 соответствует варианту 9, так как в методических материалах приведено десять вариантов. Некоторые формулировки первых лабораторных используют термины C++, поэтому в проектах применены равнозначные средства C#. Например, чистые виртуальные функции представлены абстрактными методами, шаблоны представлены обобщениями, а контейнеры STL представлены коллекциями .NET.
